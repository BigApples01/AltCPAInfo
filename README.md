# AltCPAInfo Workflow

Decision-first, reproducible survey processing workflow for Alternative CPA Pathways data.

## Data placement

Place the raw CSV at:

```text
data/raw/Alternative_CPA_Pathways_Survey.csv
```

## Quick start

```bash
python -m pip install -e .[dev]
make lint
make test
```

## Pipeline commands

```bash
python -m altcpa codebook
python -m altcpa build-clean
python -m altcpa validate
```

Equivalent make targets:

```bash
make codebook
make build_clean
make validate
```

## Outputs

### Codebook

`make codebook` writes structure-focused artifacts:

- `reports/codebook/columns.csv`
- `reports/codebook/value_examples.json`

### Clean build

`make build_clean` writes:

- `data/clean/clean.parquet`
- `reports/codebook/column_map.csv`
- `data/interim/multiselect_long.parquet` (if multi-select patterns are detected)

### Validation

`make validate` runs schema and rule checks on cleaned data.

## Optional decision packet (implemented, not auto-run)

A decision packet module is included and only outputs tables/JSON (no narrative text). To run later:

```bash
python -m altcpa decision-packet
```

Outputs go to:

- `reports/decision_packet/*.csv`
- `reports/decision_packet/*.json`

## Guardrails

- No interpretation or narrative analysis is generated by this workflow.
- No analysis command is auto-run by default.
